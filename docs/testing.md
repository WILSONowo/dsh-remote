# 测试

默认测试使用合成设备、随机临时凭证和隔离临时目录；网络测试只启动本机回环服务并使用随机端口。
不会探测局域网设备、读取实际安装的用户数据或调用模型。测试里的域名、路径和地址是合成输入，不是部署配置。

```sh
npm ci --legacy-peer-deps
npm run build
npm test
./gradlew testDebugUnitTest assembleDebug
```

## 可选 SDK 与后端联调

这些测试默认跳过，不自动查找本机安装。显式设置以下环境变量后运行 `npm test`：

- `DSH_TEST_RUNTIME`：独立准备的 DeepSeek Harness `0.2.1-rc.5` SDK 的 `node_modules/@deepseek-ai` 目录。只包含包，不包含用户配置、会话或凭据。
- `DSH_RELAY_BACKEND`：已运行 `npm ci` 和 `npm run build` 的 `dsh-remote-backend` 仓库绝对路径。
- `OPENSSL_BIN`：OpenSSL 可执行文件路径；不设置时使用 PATH 中的 `openssl`。TLS 测试现场生成一天有效的临时证书并在结束后清理。

SDK 测试使用实际协议类和合成业务服务；后端联调仅使用本机临时服务器。环境变量指向无效目录时测试失败。
发布前可同时启用两项，验证 HTTP、WebSocket、SSE、设备隔离、证书验证和断线重连。

实际部署或外部网络的测试必须单独显式配置目标和凭证，不能加入默认测试或提交真实数据。

## 插件设置页

中英文词条及语言切换测试随 `npm test` 运行；设置 `DSH_TEST_RUNTIME` 后会使用真实宿主的 LocaleRuntime。

使用同一个 SDK 路径可启动隔离的界面预览：

```sh
node dsh-remote-access/scripts/preview-settings.mjs
```

该预览要求 SDK 中包含 `dsh-web-frontend`、`dsh-client-locale` 和 `dsh-client-ui-theme`，目前适配 `0.2.1-rc.5`。它复用宿主控件和主题，仅在回环地址监听，接口使用合成数据，不加载真实电脑配置或连接服务器。
检查中英文切换、深浅色、窄窗口、保存、二维码、配对确认、电脑和手机重命名、撤销和域名增删；预览工具栏只属于测试环境，不进入插件包。

## 连接开关与电源请求

默认测试使用合成配对、回环 HTTP/WebSocket/SSE 和模拟电源进程，覆盖总开关、凭证保留、待配对失效、活动时间持久化及电源进程清理。

Windows 可显式设置 `DSH_TEST_POWER=1` 后运行 `npm test`，短暂启动隐藏电源辅助进程验证系统 API 与退出清理。测试结束释放请求，不修改电源计划；未设置时跳过真实电源测试。

界面检查包括“添加”中的服务器/直连分支、六位码/电脑确认、总开关、最近连接时间、唤醒开关和可信域名管理。用预览中的 `Toggle missing settings` 模拟旧后台缺少接口，检查提示与开关禁用；再次切换并点击重试，检查设置恢复。

## Android 扫码真机检查

扫码模型随 APK 内置。单元测试验证连接信息筛选，不代表相机识别效果。真机需检查直连和服务器二维码、远近距离、横竖屏、补光、点击对焦、多个二维码、首次权限拒绝后重试，以及切到后台再返回。使用合成二维码测试识别；只有显式指定测试服务器后才执行实际配对。不保存相机帧或打印配对内容。

## 局域网发现

默认测试不发送局域网组播：插件使用模拟发布器验证临时发现会话、过期、关闭、锁定、独立凭证及管理权限；Android 使用合成服务记录和回环 HTTP 验证多地址、去重、错误响应、重定向拒绝及不发送凭证的探测。

真实网络验收必须先显式指定测试电脑、设备及局域网，再打开电脑配对页面进行。检查：单电脑及多电脑、IPv4/IPv6与多网卡、动态端口、两台设备分别配对及独立撤销、旧码或旧发现缓存、关闭配对窗口、权限拒绝、网络切换、后台返回和组播被阻止时的 IP/扫码退路。未完成真机验收不能将编译或单元测试视为自动发现成功。

Android 当前 targetSdk 为 36；升级至 37 时按官方局域网权限要求适配，不能静默跳过授权。预览脚本中的电脑、地址和配对码均为合成数据。

## Android 导航与多电脑检查

`testDebugUnitTest` 包含 Robolectric Compose 测试，覆盖未连接时打开设置、返回连接页、切换电脑、相同地址的不同记录、六种主题布局、小屏和大字号。首次运行会下载 Android 测试运行时。缓存、置顶和工作区按电脑隔离；历史缓存、待办切换及延迟响应另有单元测试。

模拟器上可安装隔离测试包，不覆盖已有 App：

```sh
./gradlew assembleDebug -PDSH_UI_TEST_BUILD=true
adb install -r app/build/outputs/apk/debug/app-debug.apk
python tests/tools/local_ui_server.py --ports 18741 18742
adb reverse tcp:18741 tcp:18741
adb reverse tcp:18742 tcp:18742
```

该构建包名为 `com.dsh.mobile.uitest`，仅关闭启动时的更新检查；连接与页面使用正常实现。测试服务只监听回环地址，不执行任务或读写电脑文件。添加 `http://127.0.0.1:18741` 和 `http://127.0.0.1:18742`，用合成配对码 `123456` 或模拟电脑确认连接。两台模拟电脑故意使用相同会话 ID，便于检查切换后是否混入另一台的会话。不要把此服务部署到实际服务器。

人工检查：未连接设置、返回与切换、两种配对入口、长名称、会话搜索与滚动、输入法弹出、多行输入、更多菜单、深浅主题及大字号。结束后停止测试服务、移除这两个 ADB 转发，并恢复模拟器的显示与字体设置。正式本地 APK 使用不带 `DSH_UI_TEST_BUILD` 的构建，核对包名和签名后再分发。

主要视口为竖屏 1200×2608、横屏 2000×1200，同时检查小屏和系统大字号。布局根据可用 dp 尺寸调整：宽度至少 600dp 的横屏使用侧边导航，其余使用底部导航。调整模拟器后需核对截图实际宽高和系统密度，不能仅凭 `wm size` 的设置值判断方向。

# DSH Remote 隐私说明

DSH Remote 是 DeepSeek Harness 的非官方第三方客户端，没有自建账号系统、广告或遥测服务。

## 数据处理

主机设置、历史缓存和主题保存在手机应用私有目录；手机设备令牌使用 AndroidKeyStore 加密保存。发送的任务、文件和审批结果交给你配置的电脑上的 DeepSeek Harness 处理。
服务器中转模式下，数据经过你配置的中转后端，但内容在手机与电脑之间端到端加密（固定电脑公钥的 TLS 1.3），中转服务器无法读取会话、文件或设备令牌。中转服务器仍能看到元数据：电脑标识、来源 IP、连接时间与流量大小。局域网直连同样只传输加密内容。
设备身份由随机值生成，与显示名称分开；新配对不采集硬件序列号或网卡 MAC。中转后端保存主机标识、注册凭证摘要、电脑显示名称和登记时间。临时扫码信息只用于本次配对，不保存在手机连接配置中。
电脑负责会话存储及模型调用；所用模型服务的数据处理方式由该服务决定。

## 外部连接与权限

应用更新会访问 GitHub Releases 或配置的下载镜像，安装前核对 SHA-256 与签名；主题市场会访问其主题来源。这些服务可能收到 IP 地址和常规请求信息。
网络权限用于连接服务和下载更新；通知与前台服务用于任务提醒；相机用于扫码；系统文件选择器用于背景、主题、证书和待发送文件。

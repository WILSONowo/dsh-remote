# DSH Remote 隐私说明

DSH Remote 是 DeepSeek Harness 的非官方第三方客户端，没有自建账号系统、广告或遥测服务。

## 数据处理

主机设置、历史缓存和主题保存在手机应用私有目录；手机设备令牌使用 AndroidKeyStore 加密保存。发送的任务、文件和审批结果交给你配置的电脑上的 DeepSeek Harness 处理。
服务器中转模式下，数据经过你配置的中转后端。TLS 在中转服务器终止，服务器可以读取转发内容；当前不提供端到端加密，请使用可信服务器。
电脑负责会话存储及模型调用；所用模型服务的数据处理方式由该服务决定。

## 外部连接与权限

应用更新会访问 GitHub Releases 或配置的下载镜像；主题市场会访问其主题来源。这些服务可能收到 IP 地址和常规请求信息。
网络权限用于连接服务和下载更新；通知与前台服务用于任务提醒；相机用于扫码；系统文件选择器用于背景、主题、证书和待发送文件。
